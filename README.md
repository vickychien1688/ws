# A4 學習單排版列印工具（老師專用）

網址：https://ws.our-reading-space.com

把 GPT 產生的學習單圖片排成 A4 滿版頁面，裝訂成冊用。與學生的跟讀平台完全分開。

## 功能
- 批次上傳圖片，依檔名自動排序；拖曳 ✥ 把手調整頁面順序
- 左側裝訂邊（預設 0.5 cm）、上下留白可調
- 圓圈頁碼：位置（置中／左下／右下／外側）、字級、起始頁號
- 第一頁是封面（不編頁碼）、可加自動目錄頁
- 頁尾文字：7 種位置、字型（黑／明／楷／圓體）、粗細、字級
- 簡單修圖：筆刷、方塊遮蓋、吸色、剪下複製貼上（圖層式，可拖曳縮放）
- 專案存檔：做好的冊子可存成專案，下次開啟繼續編輯
- 輸出：⬇ 下載 PDF（300dpi）或 🖨 列印（可選「儲存為 PDF」）

## 更新方式
用新版檔案覆蓋 `index.html`，再用 GitHub Desktop commit + push，約 1 分鐘後生效。

## 注意
`CNAME` 檔是自訂網域設定，不要刪除。
